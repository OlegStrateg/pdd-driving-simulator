# Практика ПДД — городской маршрут · 0.3.0 preview

Режимы **2D / 3D** переключаются кнопками или клавишей **V**. Перед первой поездкой — пошаговая проверка управления. Доступны полный маршрут и короткие упражнения «Уступить пешеходу» и «Приоритет и ДТП».

Офлайн-симулятор учебного вождения по ПДД РФ. Самостоятельный проект: код и данные теоретического тренажёра `pdd-exam-trainer` не используются.

## Запуск в Chrome

1. [Откройте последний проверенный preview-релиз и скачайте pdd-driving-simulator.zip](https://github.com/OlegStrateg/pdd-driving-simulator/releases) и распакуйте.
2. Откройте `chrome://extensions`, включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение / Load unpacked** и выберите распакованную папку: **manifest.json находится прямо в ней**.
4. Откройте меню расширений Chrome → **Практика ПДД** → **Открыть симулятор**.
5. Нажмите **Начать поездку**. Включите левый поворотник клавишей Q, подождите немного и нажмите W.

Расширение запрашивает доступ только к overpass.private.coffee для загрузки выбранной местности и не содержит аналитики. 3D работает на Babylon.js / WebGL; движок, модель автомобиля и текстуры включены в установочный ZIP. Учебный маршрут и сохранённая местность работают офлайн. Только явная загрузка нового участка обращается к Overpass API (данные OpenStreetMap) с выбранными координатами.

## Реальная местность

На стартовом экране нажмите **Реальная местность**. Кнопка **Москва-Сити · уже в архиве** открывает готовый участок без сети. Для другого места выберите город из списка или введите координаты, затем **Загрузить участок**. На предпросмотре показаны улицы, здания и красная точка старта. Нажмите **Ехать по этим улицам**. Кнопка **Открыть сохранённый** восстанавливает последний участок без сети.

Геометрия дорог и контуры зданий взяты из OpenStreetMap; это не фотограмметрия. Фасады условные, поверхность плоская. Дорожные знаки, приоритеты и ограничения для реальных улиц не проверены: режим ознакомительный, без оценки ПДД. Область ограничена примерно 700×700 м. На реальной местности доступен 3D, 2D сохранён для учебного маршрута.

Старый файл install/pdd-driving-simulator.zip в исходниках — архив версии 0.2. Используйте ZIP из Releases.

## Управление

| Клавиша | Действие |
| --- | --- |
| W / ↑ | Газ |
| S / ↓ / Пробел | Тормоз |
| A D / ← → | Руль |
| R, удерживать | Задний ход |
| Q / E | Левый / правый поворотник; повторное нажатие выключает |
| X | Выключить любой поворотник; после завершённого поворота он также отключается автоматически |
| V | Переключить 2D / 3D без перезапуска поездки |
| C | Следящая камера / весь маршрут |
| Esc | Пауза |

Русская раскладка поддерживается через физические коды клавиш. При потере фокуса поездка автоматически ставится на паузу.

## Маршрут и проверяемые ситуации

Садовая → Набережная → Зелёный проспект → Парковая → Садовая → парковочный карман.
Следуйте светлой линии и последовательным контрольным точкам. Все повороты вокруг квартала — налево. Справа у STOP поворот запрещён.

- Лимит 40 км/ч; превышение записывается один раз за непрерывный эпизод.
- STOP: остановка передним бампером перед белой линией, затем продолжение.
- Светофор: остановка перед линией на запрещающий сигнал.
- Пешеход на зебре и автомобиль на главной дороге: уступить при конфликте.
- Сплошная линия, выезд за пределы дороги, столкновения, запрещённый поворот.
- Сигнал перед началом движения и манёвром.
- Парковка: вся машина в зелёном кармане, параллельно дороге, неподвижно 2 секунды.
- Журнал нарушений с временем и правилом. Красное уведомление содержит причину и совет. Основной протокол — читаемый HTML; печать / PDF через браузер. JSON оставлен отдельной диагностической кнопкой.

**Это учебная симуляция, не официальный практический экзамен и не замена инструктору.**
Штрафные баллы ГИБДД не моделируются. Жёлтый в этом сценарии запрещает въезд: исключение экстренного торможения не моделируется.
Порог раннего поворотника 0,6 с и выдержка парковки 2 с — игровые условия, не нормативные величины ПДД.
ДТП останавливает всю сцену и завершает попытку. Проверяются габариты автомобилей, встречная полоса, поворот из встречной полосы и задний ход на перекрёстке. Проверка пешехода учитывает занятость перехода и габариты автомобиля, включая медленный въезд; одно событие не дублируется каждый кадр.

Мир упрощён: один управляемый автомобиль, один поток на главной дороге и один пешеход. Нет полной модели городского движения, экзаменационных упражнений или повреждений автомобиля.

## Разработка и проверки

Node.js 22+. Пользователю нужен готовый ZIP из Releases. Для сборки исходников требуются npm-зависимости и сеть для загрузки ассетов.

```sh
npm install
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
```

Сборка помещает приложение, зафиксированную версию Babylon.js, модель Car Concept и CC0-текстуры в `dist/extension`. Происхождение и SHA256 загруженных ассетов записаны в assets/sources.json. Playwright нужен только для браузерных тестов.
GitHub Actions выполняет unit-тесты, упаковку и браузерный сценарий; снимки и отчёт публикуются как артефакты проверки.

Автотесты Chromium не заменяют ручную проверку **Load unpacked в установленном Google Chrome**. Факт прохождения следует смотреть в Actions, а не выводить из наличия файлов тестов.

## Архитектура

- `extension/car.js` — движение и габариты.
- `extension/level.js` — карта, маршрут, сигналы, участники движения, справочник правил.
- `extension/engine.js` — последовательность маршрута, события и протокол.
- `extension/render.js` — оригинальная процедурная графика, камера и миникарта.
- `extension/app.js` — интерфейс, клавиатура, пауза и экспорт.
- `tests/` — проверки правил и пользовательского пути.
