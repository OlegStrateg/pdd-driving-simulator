# Практика ПДД — городской симулятор

Самостоятельный учебный симулятор вождения по ПДД РФ. Не связан с кодом теоретического тренажёра pdd-exam-trainer.

Разработка первой версии ведётся в ветке `feature/driving-simulator`.

План: офлайн-расширение Chrome Manifest V3, оригинальная Canvas-графика, один городской маршрут, управление, дорожные ситуации и протокол ошибок. Учебная симуляция не заменяет занятия с инструктором или официальный экзамен.
