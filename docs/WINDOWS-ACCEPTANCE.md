# Приёмка Windows-симулятора: Москва-Сити
Дата: 2026-09-25
Статус: НЕ РЕАЛИЗОВАНО, НЕ ПРОВЕРЕНО. Это критерии приёмки, не отчёт о готовности.

## Согласованный результат
Отдельное приложение Windows на Unreal Engine 5. Первый результат — законченная десятиминутная поездка по маршруту длиной 1–2 км в небольшом районе Москва-Сити. Существующий 2D-тренажёр сохраняется. Репозиторий: OlegStrateg/pdd-driving-simulator; текущая ветка: feature/driving-simulator.

## Проверка доступности исполнения
- [ ] Доступна Windows-машина, на которой запускаются команды и Unreal Editor.
- [ ] Установлены согласованная версия UE5 и поддерживаемые инструменты сборки C++.
- [ ] Зафиксированы CPU, GPU, видеопамять, RAM, разрешение и настройки качества тестового компьютера.
- [ ] Подтверждены права использования и распространения всех моделей, текстур, анимаций и данных карты.
- [ ] Проверена пригодность модели Москва-Сити на уровне улицы: фасады, масштаб, дороги, коллизии. Один скриншот или наличие страницы Sketchfab этого не подтверждает.
- [ ] Создан и успешно упакован минимальный UE-проект; упакованное приложение запущено на тестовой Windows-машине.

Обнаружено в текущей сессии: локальный запуск команд завершился ошибкой CreateProcessWithLogonW failed: 267. Наличие UE на компьютере проверить не удалось. В дереве репозитория на коммите 28fadd2564288ca8b451efff8b96c395f0b18d23 нет .uproject, Unreal-карт и детализированных моделей района. Проверки браузерной версии не являются проверками Windows-игры.

## Порядок исполнения
1. Восстановить доступ к среде, проверить сборку и целевой компьютер.
2. Собрать один показательный перекрёсток с дорогой, фасадами, автомобилем и анимированным пешеходом. Проверить его из водительского кресла в упакованной игре.
3. После визуальной проверки расширить этот участок до целого маршрута. Для готовых ресурсов City Sample отдельно проверить совместимость и лицензии; это не готовая Москва.
4. Настроить управление, коллизии, транспорт и пешеходов.
5. Связать дорожную геометрию с учебными заданиями и проверкой ПДД. Подготовить разбор и повтор ситуации.
6. Собрать установщик и пройти нижеприведённую приёмку с записью. Только после этого выдавать сборку как готовую.

## Правило отчёта
Для каждого ID указать PASS, FAIL или NOT TESTED, версию сборки, фактический результат и ссылку на доказательство. PASS браузерного теста не переносится на UE. Сборка с FAIL или NOT TESTED по обязательным строкам не называется готовой. Отдельно раскрывать условные фасады, непроверенную точность улиц и отсутствующие механики.
